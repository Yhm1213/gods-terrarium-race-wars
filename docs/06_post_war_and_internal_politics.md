### 2.1 路线对立与政治张力累积公式

$$\Delta \text{Tension} = (\text{Ideological Mismatch}) \times \text{Oppression Factor} - \text{National Stability}$$

* **典型冲突场景 1**：国家已确立【长者议会共和】，却通过军功上位了一个【残暴暴君】。暴君试图废除议会解散法庭，平民怨气冲天，政治张力每秒暴涨！
* **典型冲突场景 2**：国家走【军阀强权独裁】，老酋长年迈体衰，却出于私心立自己体弱的【正统皇子】为储君。麾下【野心军功将】怒不可遏，暗中调集精锐谋反！

### 3.1 领地切分演进：Voronoi 聚落双核切分法 (Dual-Cluster Voronoi Partition)
* **废弃机械中轴线**：机械切割会导致农田与粮仓全归一方、新图腾刷在绝壁孤岛或悬崖，造成寻路流场除以零崩溃（`NaN`）；
* **双核自适应扩散**：
  1. 系统在原文明领地内检索两个人口最密集的聚落重心点（重心 A：主基地老图腾；重心 B：边防兵营/工坊要塞）；
  2. 以重心 A 与 B 为发生核（Seeds），沿领地瓦片图运行距离场 Voronoi 扩散；
  3. **孤岛平滑修剪协议**：任何与新图腾无直接陆地连通路径（或被山脉湖泊截断、面积 $<4$ 格）的碎片飞地，**一律直接脱离并重置为中立荒原**，彻底杜绝孤岛困死死循环！

### 3.2 战力动态平衡：叛军【自由之怒】（Wrath of Liberty）
* 正统派继承了坚固的石墙与 80% 高阶禁卫军，叛军初始纸面实力处于劣势；
* **战时狂暴补偿**：叛军在分裂瞬间全员激活【自由之怒】增益（持续 45 秒）：
  * 攻击速度 $+30\%$，移动速度 $+20\%$；
  * **完全免疫士气溃散**，战意高昂；
  * 使得内战爆发前 45 秒形成均势血腥绞杀，极具观赏性与戏剧张力。

### 3.3 四大防碎片化协议（Anti-Balkanization Protocols）
防止长期挂机中文明无限分裂为几十个单兵城邦，导致性能雪崩：
1. **人口分裂门槛协议**：文明总存活人口必须 $\ge 12$ 人方可触发图腾裂变；
2. **分裂冷却协议**：同一文明发生一次政治分裂后，进入 **300 秒（5 分钟）国家凝聚期**，期间张力清零且绝对免疫再次裂变；
3. **微型飞地坍塌协议**：任何由于战火或割地形成的小于 4 格的孤悬飞地，在 30 秒内自然消融归还荒野；
4. **全图政权容量硬锁**：全大陆活跃合法政权上限硬锁为 **16 个**。当达到 16 个国家时，国内政治张力蓄满 100 不再分裂建国，而是自动转为【宫廷流血暗杀/首领单挑决斗】。

### 3.4 世袭大随机性：皇子体质盲盒与继承意外大转盘 (Dynastic Accidents)
世袭制绝非死板的平铺直叙，而是充斥着荒诞、惊喜与未知命运的戏剧盲盒。**全部依托小人现有的物理实体（Mass、HP、外挂器官、行为状态），零虚空复杂面板**：

#### 1. 皇子体质盲盒（依托物理与变异生成）
皇子降生时，物理硬件与行为积木随机大开盲盒：
* **【天生神力蛮王】**：质量 $\text{Mass} = 1.8$，生命上限 $+50\%$，手持重木棒，日常极度好斗爱抓平民摔跤；
* **【咳血弱质皇子】**：生命上限仅 $40$，走几步就因体虚进入 `SLEEPING` 打瞌睡状态；
* **【异化突变怪胎】**：继承了隐性变异，长出四条虫腿或高压瓦斯腹腔，被保守派祭司视为“不祥妖孽”；
* **【浪荡酒鬼皇子】**：极度嗜酒，常在猪圈或酒窖喝得酩酊大醉，容易做出荒唐国策；
* **【荒野落难私生子】**：老皇年轻时在边境打猎留下的种，在荒野当伐木工或猎户，手持粗石镐。

#### 2. 老皇帝驾崩时刻的【继承意外大转盘】
当老皇帝咽气瞬间，系统触发纯事件驱动的离奇继承轮盘：
* **[40% 正常顺位即位]**：大皇子顺利加冕。若即位者是个醉鬼或弱质，国家将面临意想不到的滑稽治国风波；
* **[15% 离奇横死意外]**：大皇子在打猎时被野猪拱死、或在河边滑倒溺水身亡，王位顺位突然砸中二皇子；
* **[15% 幼主登基，权臣摄政]**：老皇暴毙留下一岁婴儿皇子，氏族第一勇士或大长者出任【摄政辅政】，老臣架空幼主引发少壮派不满；
* **[15% 遗嘱口齿不清 / 双胞胎抓阄]**：老皇临终前指错人，或双胞胎分不清长幼，兄弟在图腾前抓阄掷骰子，输的一方掀桌拔刀；
* **[15% 荒野私生子带兵夺门]**：流落民间的私生子带着一群猎户兄弟持骨矛冲入皇都，亮出皇家信物强抢王冠！

#### 3. 绝嗣角斗空盘重铸（Extinction Failsafe）
* **场景**：老皇帝寿至 120 岁但皇子因战争/疾病全部死绝，国无储君；
* **零断代安全兜底**：系统拒绝空指针崩溃，自动执行全族硬汉筛选：
  ```javascript
  // 杜绝虚空政治力，纯按物理战斗力推选第一猛士
  const newKing = clan.units.reduce((max, u) => 
    (u.mass * u.hp > max.mass * max.hp) ? u : max
  );
  ```
* **政体自然坍塌**：新皇登基后，市政路线自动从【血统世袭皇权】自然坍塌重构为【军阀强权独裁】。

#### 4. 双等位基因掩码防伪（Anti-Fraud Succession Triad）
杜绝随从、敌国卧底或骷髅兵冒充皇室私生子引发非法夺嫡，私生子认亲必须同时通过三大底层断言：

const isValidRoyalHeir =

### 3.5 多皇子派系暗流涌动模型（The Princely Factions）
当老皇帝壮年有多名成年皇子时，各皇子自发凝聚不同社会阶层：
* **大皇子【正统法统派】**：宫廷萨满与禁卫军精锐支持（世袭路线）；
* **二皇子【边防军阀派】**：长期在边境带兵砍杀，边防野战军全力拥戴（军阀路线）；
* **三皇子【民粹行会派】**：暗中控制粮仓与工匠作坊，平民与奴工拥戴（共和路线）。
老皇帝在世时互相使绊子、告黑状；老皇帝一旦驾崩且未和平交接，直接引爆**【图腾裂变大内战】**！

### 3.6 分裂政权的法理自洽（QA 防死锁与孤儿实体回收）

## 四、 战后处置五重收束与流寇生态位（Post-War Models）

对外战争胜利后，战胜国依首领性格与国策执行处置：
1. **【残酷奴役】**：战败者带枷锁采矿，设奴隶怨气值，蓄满向荒野突围独立；
2. **【和平同盟】**：领地合并，享受一等公民待遇，合并兵团编制；
3. **【二等附庸】**：保留自治图腾，每季向宗主国上缴 30% 贡赋；
4. **【驱逐流放】**：残兵携图腾火种逃入深山，成为流寇政权（Outlaws）；
   * **弱小流寇乞讨与保护费生态位（Bandit Tribute/Begging）**：
     * 当流寇战力严重弱于邻近帝国（战力比 $<0.2$）时，强盗**绝对禁止无脑正面冲锋大军自杀**；
     * 自动转入【边境盘剥游荡】：在帝国商路收取单次 1~2 份干粮过路费，或在粮仓围墙外跪地乞讨；
