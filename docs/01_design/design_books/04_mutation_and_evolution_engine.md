## 一、 动作通道仲裁协议（Action Channel Protocol）

彻底根除小人“躺在地上装死却像火箭一样贴地滑翔穿墙”的状态机冲突：
小人的所有行为严格划分至 **3 个独立正交的动作轨道（Channels）**：

```
[轨道 1: 机动位移轨 (Locomotion Channel)] -> 正常奔跑 / 冲撞 / 飞扑 / 强制静止
[轨道 2: 姿势姿态轨 (Stance Channel)]    -> 直立站立 / 倒地装死 / 钻入地底 / 身体膨胀
[轨道 3: 释放喷射轨 (Emission Channel)]  -> 体液喷洒 / 闪电释放 / 毒气散播 / 叫喊
```

* **互斥仲裁法则**：
  * 同一轨道内的动作严格互斥（如 `PLAY_DEAD` 装死强制锁定 `Stance` 轨为倒地，并将 `Locomotion` 轨速度矢量强制归零）；
  * 处于 `PLAY_DEAD` 姿势时，严禁响应外部给予的 `SLIP_BANANA`（滑铲）机动动作，只能触发 `Emission` 轨的毒气或酸液释放。

## 二、 CFG 语法产生式与前向掩码张量过滤 (Pruning Garbage Combos)

### 2.1 产生式文法分层（Hierarchical CFG）
每个动作组合严格遵守上下文无关文法产生式：
$$\text{Skill} \rightarrow \text{ContextTrigger} + \text{PhysicalAction} + \text{ElementAffinity} + \text{ModulatedQuirk}$$

### 2.2 相容性张量掩码（Compatibility Tensor $\mathbf{C}[T, A, E, Q]$）
算法在抽选词条时，采用**前向概率掩码（Forward Masking）**，而不是生成后再回溯：
* 若 `Trigger` 选定为 `ON_ENTER_WATER`（浸入水体），则其级联的候选 `Element` 概率掩码中，`FIRE_BLAST` 自动重写为 `STEAM_EXPLOSION`（高压水蒸气），既保证物理真实感，又避免逻辑空转；
* 若 `Action` 为 `BURROW_UNDERGROUND`（钻入地底），则其候选 `Quirk` 中剔除 `SLIP_BANANA`（滑倒）。

### 2.3 效用期望 - 混乱方差双门限过滤（The Dual-Threshold Filter）
$$\mathbb{E}[U(S)] = \Pr(T \mid \text{Combat}) \cdot \left[ V_{\text{base}}(A) \times \kappa(E, M) - C_{\text{penalty}}(Q) \right] + \text{Synergy}$$
$$\sigma^2(S) = \text{ChaosFactor}(Q) \times \Pr(T \mid \text{Combat})$$

```
                         有效效用期望 E[U(S)]
                                  ▲
                                  │
          【标准正向技能】        │      【神仙级生草神技】
          (低方差, 高期望)        │      (高方差, 高期望)
          直接允许通过             │      ★ 系统重点保全与推送！★
                                  │
  ────────────────────────────────┼──────────────────────────────► 混乱方差 σ²(S)
                                  │   (戏剧性/意外度)
          【纯自残垃圾词条】       │      【滑稽恶搞词条】
          (低方差, 负期望)        │      (高方差, 轻微负期望)
          ✖ 强制静默重抽 (Reroll)  │      ✔ 允许保留 (爆笑看点)
                                  │   (Floor = -0.15)
```
1. **绝对垃圾截断线**：若 $\mathbb{E}[U(S)] < -0.15$（纯负效用，如“受到暴击时原地眩晕2秒并向友军打喷嚏”），算法直接在后台静默重抽；
2. **生草保护区**：若期望值轻度亏损，但混乱方差 $\sigma^2(S) > 0.8$（如平地摔倒但无敌滑铲铲飞敌将），系统不仅保留，而且打上“稀有爆梗”标签，赋予战报播报特权！

## 三、 孟德尔双倍体显隐性与基因驱动（Gene Drive Drift）

废除粗暴的“弑君登基即 100% 暴力改写全族”，重构为**基于群体遗传学的平滑演化流转**：

### 3.1 双等位基因编码（Diploid Allele）
每个小人的基因座保存双等位基因：$\text{Locus} = \langle \text{Allele}_{\text{maternal}}, \text{Allele}_{\text{paternal}} \rangle$
* 原生种族基底为隐性基因（$D_{\text{wild}} = 0.2$）；
* 新突变等位基因为不完全显性（$D_{\text{mut}} = 0.7$）。

### 3.2 模式 A 基因驱动渐进演化（The Gene Drive Model）
当英雄弑君登基或图腾神火共鸣时，激活**基因驱动偏向（Gene Drive）**：
$$P(\text{传给后代}) = 0.85 \sim 0.95 \quad (\text{正常繁衍为 } 0.5)$$

```
全族同化率 %
 100% ┼──────────────────────────────────── 渐进完全同化 (Fixation)
      │                                    ╭──────
      │                                   ╭╯
  50% ┼                                  ╭╯  2~3 代自然选择：
      │                                 ╭╯   劣质变异在代际繁衍中衰亡
      │                     ╭───────────╯    优质变异席卷全族
   0% ┼─────────────────────┴────────────────────────► 代际繁衍 (Generations)
      T=0 (英雄登基, 赋予基因驱动偏向)
```
* **算法优势**：
  1. **防止瞬间断代与生态休克**：全族同化经历 $2 \sim 3$ 代幼崽更替，老一代仍保有原有职业战力；
  2. **自然淘汰自杀型突变**：若该突变在实战中表现极差，携带该基因的后代会在捕猎中高频死亡，使得该突变在种群中自然萎缩跌出基因池，算法具备了**自我愈合纠错能力**。

### 3.3 部落大分裂的滞后回线（Hysteresis Loop）防震荡
* **分裂触发条件**：互斥派系各自占比持续 $30\text{秒}$ 维持在 **$\ge 35\%$** 以上，且部落总人口 **$N \ge 12$**；
* **分裂取消条件**：只有当某一方占比跌破 **$20\%$** 时才取消分裂判定。
* 彻底消除了小样本人口波动（如死了一个人比例微跌）引发的状态机高频抖动。
