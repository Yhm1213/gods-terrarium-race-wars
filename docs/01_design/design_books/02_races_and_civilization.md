## 三、 生物种族 (Race) 与政治实体 (Faction/Kingdom) 的正交解耦与一族多国模型

在经典沙盒与文明推演中，**“生物学物种 (Race)”绝不等于“地缘政治王国 (Faction)”**。现实历史中人类有数百个彼此征伐的帝国与城邦，奇幻史诗中兽人氏族与精灵王庭亦常年处于血腥内讧。将二者机械硬编码绑死是造成“开局死板、每一局都一样”的根本根因。

```

│                   种族与政权正交解耦架构 (Orthogonal Decoupling)       │
├───────────────────────────────────┬────────────────────────────────────┤
│   生物学种族 (RaceId: 0 ~ 11)     │    地缘政治实体 (FactionId: 1 ~ 16)│
├───────────────────────────────────┼────────────────────────────────────┤
│ • 决定身体形态、体质与基础 Mass    │ • 拥有独立的法理主权与国号 (Kingdom Name)
│ • 决定四大生存代谢范式 (农耕/捕猎) │ • 拥有独立的阵营图腾营火 (Camp Totem Pos)

```

### 3.2 运行期同族分裂与新政权诞生 (Dynamic Schism & Emergent Kingdoms)

除了在沙盒开局自选“一族多国剧本”，游戏在运行推演中还会自发涌现同族新王国：
1. **政治大分裂 (The Great Schism)**：当任何王国内部政治张力蓄满 100，或老皇帝驾崩引发两皇子夺嫡内战时，领地触发双核 Voronoi 裂变；
2. **分配新 Faction 槽位**：从 1~16 的未占用政权池中动态分配全新 `FactionId`；
3. **血统同构、政权敌对**：叛乱军的生物学 `RaceId` 与母国完全一致（共享生理抗性与变异器官），但戴上不同配色的反叛旗帜，并将母国判定为宿敌（仇恨值锁定 200），爆发惨烈的同族同室操戈；
4. **政权消亡与槽位回收**：当某个王国的图腾被彻底拔除、人口归零时，其 `FactionId` 被回收重置为中立，留给未来可能爆发的新王国或叛军。

### 3.3 异族附庸、战俘奴隶与多民族帝国 (Multi-Ethnic Empire & Slaves)

正交解耦彻底释放了沙盒社会的复杂性：
* **战俘与奴役**：战争中被击溃但未斩首的异族小人，可被胜利国俘获并打上 `IS_SLAVE` 状态掩码，归属于胜者 `FactionId`；
* **异族奴隶经济**：兽人奴隶拥有强大的 Mass 质量与抗击打能力，在人类帝国的矿山与采石场被奴役采矿；
* **奴隶起义隐患**：若奴隶人口超过自由民 $50\%$，且该城邦粮仓亏空，异族奴隶将爆发斯巴达克式【角斗士奴隶起义】，推翻图腾夺取政权！

  * 若全族活动魔像全部断电石化，且无任何建造单位存活，系统判定该阵营进入【中立古代遗迹化】；
  * **阵营普查解耦**：立即将该文明的 Faction ID 变更为 `NEUTRAL_RUINS`，释放宝贵的全局阵营配额，彻底破除全图 16 国硬锁被僵尸阵营占满的死锁风险！

## 五、 物理碰撞推力与相容性过滤（延续严格数学基线）

### 5.1 质量对撞反冲公式
单位 A 与 B 正面相撞时，位移反冲距离与质量成反比：
$$D_A = \text{Force} \times \frac{\text{Mass}_B}{\text{Mass}_A + \text{Mass}_B}$$
质量 2.5 的晶石魔像撞击质量 0.5 的地精，地精飞退 83%，魔像几乎纹丝不动。

### 5.2 生理相容性语义重映射（Semantic Remapping）
若某族抽中相克基因（如森灵精灵抽中【易燃瓦斯自爆】），算法自动将火系词条降级映射为草木系的【剧毒孢子弹射】或【棘刺散射】，杜绝种族自杀悲剧。
