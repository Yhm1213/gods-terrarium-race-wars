# 《神之蛐蛐缸：万族争霸》模块设计文档：08 编年史与矮人要塞式生草战报 (v2.0 专家修订版)

---

## 一、 核心设计目标与文学基调

让游戏的“放置挂机观赏性”达到极致的核心叙事系统。
摒弃低幼廉价的美式卡通滑稽，全面吸收《矮人要塞》(Dwarf Fortress) 与《极乐迪斯科》(Disco Elysium) 的精神内核，确立：
**“冷酷客观的解剖学严肃荒诞” $\times$ “崇高史诗仪式感与琐碎翻车意外的剧烈反差”**。

* **文学原则**：
  1. **一本正经地胡说八道**：无论现场多么生草翻车，文本永远用冷峻、严谨、崇高或冰冷的词汇陈述事实；
  2. **万物皆有因果**：拒绝凭空胡诌的段子，每一条战报必须百分之百来源于底层的物理碰撞、生理变异、技能判定与多年宿怨；
  3. **高信噪比**：垃圾平砍自动静默折叠，唯有关键暴击、断肢、奇迹逆转与意外翻车才登堂入室。

## 三、 宿怨账本图谱（The Blood Ledger & Grudge Network）

为微观小人注入“鲜活恩怨”的因果网络，消除陌生人随机互殴的廉价感：

```
小人实体 [Unit]
  └── BloodLedger (宿怨清单, 容量最大 3 条)
       ├── Grudge[0]: { targetId: "goblin_89", event: "BIT_OFF_EAR", timestamp: 1420 }
       └── Grudge[1]: { targetId: "orc_boss",  event: "BURNT_HOME",   timestamp: 3200 }
```

### 3.1 宿怨生成机制
当一个小人遭受以下极端创伤且幸存时，永久记录仇敌身份：
* 被敌方斩断肢体或打烂变异器官；
* 家园房屋或部族祖宅在眼前被敌方点火烧毁；
* 亲生血亲或师父在身边阵亡。

### 3.2 战场重逢触发【宿命因果对账】
当战场感知范围内检索到宿怨仇敌时，小人进入**“宿仇狂暴（Vendetta Frenzy）”**态，战报系统打出金框专属排版：
> **`[宿命清算 18:42]`** 
> 矮人士兵 **【断指·铜须】** 在乱军中一眼认出了十年前咬掉他左耳的森灵刺客 **【影叶】**！
> *“铜须发出了撕裂声带的怒吼，无视两侧攒射而来的飞箭，将全身花岗岩重盾的全部动量狠狠砸向了那个宿命的仇敌！”*

## 六、 战报终端性能与限流吞吐机制（Log Buffer Management）

为杜绝 1000+ 单位高频交火引发前端 DOM 节点爆炸与内存泄漏：

```
[原始战斗事件流 (100+ events/sec)]
               │
               ▼
   【事件过滤器与节流阀 (Throttle & Filter)】
   • 丢弃普通无暴击平砍事件
   • 相同动作 0.5 秒内仅聚合一次 ("前线 8 名步兵正在激烈盾击缠斗...")
               │
               ▼
   【双缓冲环形队列 (Ring Buffer)】
   • 内存数组严格限制最大长度: MAX_LOGS = 100
   • 采用循环下标指针，零 Array.shift() 内存重分配
               │
               ▼
   【虚拟 DOM / 限制节点更新 (Virtual Log Renderer)】
   • DOM 容器内最多保留 60 个可视元素节点
   • 超出范围自动从顶部 removeChild，维持极低重排（Reflow）开销
```
