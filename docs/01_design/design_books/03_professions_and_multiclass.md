# 《神之蛐蛐缸：万族争霸》模块设计文档：03 职业与多职业兼职系统 (修订版)

> **修订说明 (v2.0)**：已吸收【战斗平衡专家】与【QA破坏者】评审意见，重点修复“4 大恶性无敌流派”（自爆毒蛙、真伤反甲刺猬、空降永久缴械、无限圣血复活），为全职业技能引入**内置冷却时间 (ICD)**、**税后伤害反弹**与**武器丢失保底**。

## 一、 核心设计理念与动作经济学控制

小人通过生活劳作与战场生死磨砺觉醒职业，兼顾观赏性与策略性。但在数值底层必须推行严格的**动作经济学（Action Economy）与反无限循环阀门**：
1. **多职兼修**：1 个生活底色 + 1 个战斗副职 + 罕见传说神职；
2. **全局内置冷却时间（ICD $\ge 1.5\text{s}$）**：所有由被动/受创激发的职业特技，强制拥有独立内置冷却，杜绝连环自激震荡；
3. **税后结算原则（Post-Mitigation Calculation）**：所有反伤、吸血均基于“实际扣除的伤害值”，严禁基于未减免前的高额伤害直接反弹。

## 二、 4 大恶性破坏流派专项修复方案

针对战斗专家与 QA 团队指出的恶性流派，落实以下具体平衡阀门：

### 1. 修复【核弹自爆地精流】（廉价以小博大秒全场）
* **原漏洞**：地精自喝毒药掉血 $\rightarrow$ 跌破 20% 触发身体膨胀火爆 $\rightarrow$ 引爆体内瓦斯造成大范围连环殉爆，低成本蒸发重甲军团。
* **重构方案**：
  * **自身伤害不计入濒死大招触发（Self-Damage Immunity for Triggers）**：自残药剂或自身引燃扣除的生命值，不激活 `ON_HP_LOW` 技能，必须承受来自**敌方外部攻击**才可触发；
  * **瓦斯殉爆伤害衰减（Blast Attenuation）**：体内瓦斯爆炸伤害引入距离衰减（核心 1 格 100%，外圈 2 格 30%），且对重盾单位附加 $50\%$ 的格挡减免。

### 2. 修复【绝对真伤反甲刺猬流】（无脑反弹致死）
* **原漏洞**：花岗岩/生铁免伤堆至 100%，敌方攻速越快被自身反弹死得越快。
* **重构方案**：
  * **税后真实扣血反弹（Post-Mitigation Reflection Only）**：
    反伤公式修正为：$$\text{ReflectDamage} = \text{ActualDamageTaken} \times 40\%$$
    若重盾手通过格挡仅受到 5 点伤害，则反弹伤害严格限制为 $5 \times 40\% = 2$ 点，绝不允许将敌方打出的未减免 100 点伤害反弹给对手！
  * **单次反弹内置冷却（ICD = 0.8s）**：防止高频小额攻击（如毒素、多段射击）在 1 秒内触发数十次反弹反死射手。

### 3. 修复【全图空降缴械神偷】（偷光武器导致无限遛狗）
* **原漏洞**：顺手牵羊把敌方弓箭偷走，弓手无武器后一直拉开距离后退，产生无限长跑遛狗死局。
* **重构方案**：
  * **失武备用战术匕首（Backup Dagger Fallback）**：武器被偷的单位，瞬间自动拔出腰间的简易小匕首，强制将战术 AI 从“远程放风筝”切换为“近身搏肉”，射程固定为 1 格，杜绝全场无限遛狗；
  * **顺手牵羊改为暂时缴械（Temporary Disarm）**：偷取武器判定改为“打落敌方武器在地面 6 秒”，敌将可就近捡起武器恢复战力。

### 4. 修复【永动圣血殉道复活链】（全员无敌互锁）
* **原漏洞**：圣血受创互奶量大于伤害量，且圣火殉道者死后全场无敌复活循环。
* **重构方案**：
  * **圣血治疗递减与内置 CD**：圣血喷洒每 2 秒最多触发 1 次，且同一单位在 5 秒内接受连续圣血治疗，治愈量递减 $50\%$；
  * **天启神职【圣火殉道者】全场仅生效一次（Once-Per-Battle Limit）**：神职复活光环被标记为“神迹耗尽”，单场战斗每个部落最多触发 1 次，复活后的单位扣除该标签，无法形成套娃复活。

## 六、 连续内存布局与零 GC 运行契约 (DOD Architecture)

为保证千人同屏下双职业行为机零 GC 稳定运行，双职业数据结构完全扁平化平铺：

```javascript
// DualClassComponent 连续 Float32Array 内存步长布局 (STRIDE = 6)
// Float32Array(TOTAL_SLOTS * 6)
const OFFSET_PRIMARY_JOB     = 0; // 0=NONE, 1=FARMER, 2=STONECUTTER, 3=LUMBERJACK, 4=HERBALIST
const OFFSET_SECONDARY_JOB   = 1; // 0=NONE, 1=SHIELDBEARER, 2=BERSERKER, 3=ASSASSIN, 4=SHARPSHOOTER
const OFFSET_CURRENT_MODE    = 2; // 0=PEACETIME_LABOR, 1=MOBILIZED_COMBAT
const OFFSET_LABOR_PROGRESS  = 3; // 生产行为进度计时器 (0.0 ~ 5.0s)
const OFFSET_CARRIED_RES_QTY = 4; // 头顶背负物资数量 (0 ~ 10)
const OFFSET_CARRIED_RES_TYP = 5; // 背负物资类型 (1=FOOD, 2=STONE, 3=WOOD, 4=MEDICINE)
```

* **状态切换零分配**：平战动员切换仅通过位运算与修改 `OFFSET_CURRENT_MODE` 完成，无任何闭包或临时对象生成；
* **分帧轻量轮询**：生产行为采用 4 帧分桶（1000 人每帧仅轮询 250 人），保证主线程单帧耗时严格 $<0.5\text{ms}$。
