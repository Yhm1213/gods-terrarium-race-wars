# 《神之蛐蛐缸：万族争霸》模块设计文档：07 上帝沙盒交互与神力系统 (v2.0 专家修订版)

---

## 一、 核心设计目标与定位
实现**“类型 3：全自由上帝沙盒”**的至高掌控感与极致观赏性。
玩家既不是微观下达繁琐指令的打工族，也不是无动于衷的无力旁观者。玩家是**凌驾于这片微缩生态缸之上的“至高天意（Deus Ex Machina）”**：
1. **微操拉偏架与生草整活**：用鼠标像抓蚂蚁一样捏起小人扔出去，看它在空中手舞足蹈，甚至空投刺客；
2. **规则法理锚定**：小人生物绝对自由互动，但世界图腾法理刚性锁死，杜绝沙盒崩溃与死锁；
3. **心流节奏与防 FOMO 导播**：挂机观战不再枯燥，神恩满溢狂欢机制与画中画导播让玩家绝不错过任何高光名场面。

## 二、 视口漫游与时间膨胀（Camera & Chrono-Controls）

### 2.1 视角平移与缩放矩阵
* **无极平滑点阵缩放 (Pixel-Perfect Smooth Zoom)**：
  * 支持从 $0.35\times$（全大陆宏观态势一览，自动渲染势力影响圈半透明迷雾光晕）到 $3.0\times$（微观微距，看清小人吃浆果吧唧嘴的可爱动作与汗滴）。
  * 采用双重缓冲与点阵采样，强制 CSS 与 Canvas 启用 `pixelated` 与 `crisp-edges`，放大后像素边缘绝对刚直锐利。
* **漫游交互操作**：
  * `鼠标右键 / 鼠标中键拖拽` 或 `WASD / 方向键`：无阻平移画布视口；
  * `鼠标滚轮`：以鼠标光标所在的世界坐标点为中心锚点等比平滑缩放。
  * `双击任意单位/建筑`：摄像机平滑巡航（Smooth LERP）至目标并自动开启聚光灯追踪。

### 2.2 时间法则控制（Chrono Modifiers）
* `⏸ 暂停 (Space / 按钮)`：全场时间定格，微粒子、魔法轨迹与箭矢悬停在半空。暂停状态下完全开放全部上帝操作（抓取、神力、检视、规划）。
* `▶ 1.0x 正常速度`：标准战斗观战与细节品味。
* `⏩ 2.0x / 5.0x / 10.0x 快进`：用于文明发展、采矿筑城与世代基因迭代的挂机加速。
* `⏪ 战果抽帧定格 (0.2x 慢动作)`：当系统检测到【首领对决一击必杀】或【神技大爆炸】瞬间，自动触发 1.2 秒的 0.2x 慢动作与电影级黑边定格，强化绝杀视觉冲击。

## 三、 上帝之手：物理引擎交互规范（The Hand of God）

鼠标光标不仅是一个普通的指针，而是玩家直接伸入微缩生态缸的**“实体化神之手”**。

```
                [鼠标左键按住活体/可动物体]
                           │
                           ▼
          【上帝神之手捏起实体 (Hovering)】
   • 小人四肢悬空乱蹬，冒出惊恐问号 💭❓
   • 立即进入「被捕获锁定状态」，清空当前攻击与施法残余 Hitbox
   • 呈现半透明金色神圣牵引线 (Rubberband Tether)
                           │
        ┌──────────────────┴──────────────────┐
        ▼                                     ▼
 [原地轻柔松开]                        [快速甩动拖拽后松开]
   • 赋予轻微垂直重力 (g=9.8)            • 计算鼠标最后 3 帧矢量速度赋感动量
   • 屁股着地弹跳爬起                    • 抛物线飞掠，受空气阻力衰减
   • 获得 0.8s 落地惊魂保护态            • 依据质量产生地面冲击波与眩晕
```

### 3.1 物理抓取的五大硬性安全边界规范 (QA/边界防范)

#### 规范 1：图腾绝对不可抓取锁（Totem Anchor Lock）
* **硬性铁律**：核心基地图腾（Totem/Base）、超级奇观巨炮与地心矿井属于世界的“法理与几何空间之锚”，**绝对禁止被上帝之手抓取或位移**。
* **反馈表现**：当玩家试图拖拽图腾时，图腾表面爆发出金色神圣锁链震颤光效，播放沉重金属撞击音，战报系统提示：
  > *“【天意受阻】图腾乃一族命脉法理之锚，不可被神之手任意拔除迁移！”*
* **设计目的**：彻底杜绝玩家直接把敌对阵营基地扔进海里秒杀的作弊行为，保护阵营战线推移与寻路流场的完整性。

#### 规范 2：世界边缘刚性截断（Rigid Boundary Clamp）
* 抛投实体计算时，严格执行边界硬截断：
  $$X_{\text{clamped}} = \max(12, \min(W_{\text{world}} - 12, X))$$
  $$Y_{\text{clamped}} = \max(12, \min(H_{\text{world}} - 12, Y))$$
* 绝对禁止实体坐标变为负值、超出边界或产生 `NaN`，防止实体掉入虚空导致引擎索引泄露或渲染崩溃。

#### 规范 3：防穿模回弹（No-clip Softlock Prevention）
* 若小人被投掷落入不可通行的深山石壁或建筑碰撞体核心，引擎在落地判定帧（Land Event）执行即时 $3\times3$ 广度优先搜索（BFS），**自动将其推挤至最近的合法可行走平地**，并产生一圈灰尘撞击粒子。

#### 规范 4：基于质量（Mass）的投掷着陆判定
* 投掷伤害与冲击波半径由物理质量（Mass）与着陆垂直速度共同决定：
  $$\text{Impact Radius} = \lfloor \text{Mass} / 40 \rfloor \quad (\text{格})$$
  $$\text{Fall Damage} = \max\left(0, (V_{\text{impact}} - V_{\text{safe}}) \times 1.5 \times \frac{\text{Mass}}{50}\right)$$
* **花岗岩重盾矮人**（Mass 90）高空砸地：落地产生 $2\times2$ 震地冲击波，震晕周围敌人 1 秒；
* **几丁质飞虫地精**（Mass 25）：受阻力大漂浮更久，落地轻巧弹起，几乎免除坠落伤害。

#### 规范 5：动作打断与幽灵判定清理（Action Cleanup Pipeline）
* 当单位被捏起的瞬间，强制执行底层清理：
  ```javascript
  unit.brain.currentAction = ActionType.AIR_SUSPENDED;
  unit.combat.activeHitboxes.clear(); // 清空悬空武器判定
  unit.combat.cooldowns.resetGlobal(0.5); // 赋予落地后内置冷却
  unit.status.add("AIRBORNE_DIZZY", 1.0); // 眩晕抗拒
  ```
  杜绝“被捏在半空依然隔空施放无敌旋风斩”的幽灵判定恶性 Bug。

#### 规范 6：天命悬空与神威反噬防死锁（Divine Suspension & Heavenly Backfire）
* **极端边缘场景**：老皇帝咽气、继承原子事务启动瞬间，被选中的继承人恰好被玩家用上帝之手捏在半空中；
* **天命悬空挂起**：加冕事务计时器暂停，小人头顶冒出金色问号王冠 `👑❓`；
* **神威反噬强制落地**：
  * 若玩家持续抓取超过 5.0 秒，天道运行规则触发【神威反噬】；
  * 一道刺目金白雷电顺着牵引线劈击震颤，强制震脱玩家的鼠标上帝之手；
  * 赋予继承人 1.5 秒不可抓取的【金身霸体 (Sacred Body)】与轻柔重力缓降，安全落于图腾前完成王位加冕事务，彻底杜绝玩家通过恶意滞空使继承事务死锁！

## 四、 智能导播画中画系统（Smart Director Picture-in-Picture）

为解决 1000+ 单位在多处战场并发爆发，玩家面临的 FOMO（Fear of Missing Out）焦虑与长时挂机视线聚焦点涣散问题：

```
|                                     +---------------------+ |
|                                     | 🔴 [LIVE 突发画中画]  | |
|                                     | 狂暴首领绝地弑君中!  | |
|                                     | [160x120 像素特写]  | |
|                                     | [点击平移镜头 ↗]     | |
|                                     +---------------------+ |
|                                                             |
|                                                             |
+-------------------------------------------------------------+
```

### 4.1 突发热点触发器（Director Threat Sensor）
导播系统在后台每秒评估全图事件威胁权重，当以下高潮事件在**当前玩家视口外**发生时，右上角平滑滑出画中画：
1. **首领单挑/围攻**：任意阵营酋长生命值低于 $30\%$ 且处于交火状态；
2. **图腾濒危**：阵营老巢图腾受到攻击且生命值首次跌破 $50\%$ 或 $20\%$；
3. **神级突变诞生**：某小人突变出稀有度 $\ge$ 传说级（Gold/Purple）器官或组合动作；
4. **超级武器充能完毕**：哥布林神风飞艇点火起飞、矮人轨道巨炮填装完毕。

### 4.2 交互联动
* 鼠标点击画中画视口：主摄像机以 $1200\text{px/s}$ 的平滑缓动曲线平移至事发点，并将主导播聚光灯切换至事件核心主角。
* 10 秒内若无进一步剧烈冲突，画中画自动淡出收起，不遮挡屏幕。

## 六、 放置心流杀手锏：神恩满溢狂欢时刻（Divine Overdrive）

针对挂机放置 15~30 分钟可能出现的疲劳感，设计阶段性**“上帝高潮反馈闭环”**：

### 6.1 狂欢触发机制
* 当玩家累积的【神恩值】达到 $100\%$ 时，UI 顶端神圣神环剧烈发光，音效响起辉煌唱诗和弦，屏幕弹出按钮：`⚡ 开启神恩满溢 (OVERDRIVE)！`

### 6.2 15 秒狂欢超载状态（15s Golden Frenzy）
1. **神力无限施展**：所有上帝技能冷却归零，神恩消耗归零！玩家可在 15 秒内如疾风骤雨般狂点天雷、狂丢金苹果、抓起敌将四处甩飞！
2. **全图黄金圣光滤镜**：全图所有小人头顶冒出狂热光环（`狂喜状态`），移速 $+50\%$，工作与采矿速度 $+100\%$，饱食度不减；
3. **生草事故狂欢**：此期间小人所有生草技能触发率提升 $200\%$（滑铲、喷火、飞艇升空）；
4. **终末烟花与收益结算**：15 秒结束时，全屏绽放神圣像素礼花，并生成一份《狂欢纪元快报》，为玩家的挂机守候提供巨大的情感多巴胺犒赏。
